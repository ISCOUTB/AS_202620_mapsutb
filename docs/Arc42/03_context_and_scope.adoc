[[section-context-and-scope]]
== Alcance y Contexto del Sistema

=== Contexto de Negocio

[options="header",cols="2,2,3"]
|===
|Socio de comunicación|Entradas al sistema|Salidas del sistema
|Aspirante / futuro estudiante|Interacción táctil (navegación en el mapa, selección de puntos de interés)|Recorrido panorámico 360°, ubicación en el mapa, ruta aproximada hacia el destino
|Estudiante actual|Interacción táctil|Ubicación en tiempo real, ruta hacia un punto de interés del campus
|Estudiante de intercambio extranjero|Interacción táctil, selección de idioma (inglés)|Interfaz en inglés, ubicación y recorrido panorámico
|Invitado a eventos|Interacción táctil|Ubicación en el mapa, recorrido panorámico de zonas del campus
|===

MAPSUTB no intercambia datos específicos de dominio con ningún sistema
externo: no consume APIs de terceros en tiempo de ejecución. El único
socio de comunicación es el usuario final, que interactúa directamente
con la app.

=== Contexto Técnico

[options="header",cols="2,3"]
|===
|Canal técnico|Entrada/salida que transporta
|GPS del dispositivo (a través de servicios de localización del sistema operativo)|Posición del usuario en tiempo real (latitud/longitud), consumida vía el paquete `geolocator`
|Almacenamiento local del dispositivo (activos empaquetados con la app)|Mapa del campus, imágenes panorámicas 360° (capturadas por el equipo), datos de zonas y puntos de interés
|===

MAPSUTB no requiere conexión a internet para su funcionamiento
principal: el mapa, las imágenes panorámicas 360° y los datos de puntos
de interés se distribuyen como activos locales dentro de la app, y la
ubicación del usuario se obtiene directamente del hardware GPS del
dispositivo a través de los servicios de localización del sistema
operativo (sin pasar por ninguna API de red).
